# CampusPulse

AI-powered campus problem intelligence system.

## Problem

College problems are usually reported individually,
making it difficult to identify recurring issues,
hidden patterns and high-priority problems.

## Solution

CampusPulse analyses campus problem reports,
detects recurring patterns, prioritizes issues,
and generates actionable insights.

## MVP

- Problem reporting
- Problem analytics
- Smart prioritization
- AI-generated insights

## Tech Stack

- Frontend: React
- Backend: FastAPI
- Database: PostgreSQL
- Machine Learning: Python & Scikit-learn
- AI: LLM API
